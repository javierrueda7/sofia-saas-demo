# Demostración — Recepcionista virtual

Demostración **estática** (solo para mostrar cómo se ve): corre completa dentro del navegador, con datos de ejemplo. No hay servidor, no se envía ni se guarda nada, y al recargar la página todo vuelve a empezar.

- Vista del **cliente**: chat de reservas con calendario de colores.
- Vista del **negocio**: panel con agenda, clientes, servicios, equipo con permisos e ingresos (entrando como dueño, recepción o profesional).

Este repositorio contiene solo los archivos compilados de la demostración.
